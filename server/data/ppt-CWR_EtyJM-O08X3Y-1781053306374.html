⚡ 聚变基本原理

  • ☀️轻核聚合 氘氚反应：D + T → He⁴ + n + 17.6 MeV，比裂变能量密度高4倍
  • 🔥劳森判据 温度>1.5亿°C，等离子体密度×约束时间 > 3×10²¹ keV·s/m³
  • 🌍燃料丰富 海水中氘含量约0.016g/L，可供人类使用数亿年
  • 🧪第一壁挑战 14.1MeV中子辐照，材料活化与热负荷 (ITER数据)
数据来源: ITER Physics Basis, 核聚变原理 (M. Kikuchi, 2020)

🌀 托卡马克 · 主流路径

  • 🔵ITER (国际热核聚变实验堆) 2025年安装第一等离子体，目标Q≥10 (500MW/50MW)
  • 🔴EAST 中国全超导托卡马克，2023年实现403秒高约束模式等离子体 (中科院等离子体所)
  • 🟢JT-60SA 日本/欧盟联合，2024年首次等离子体，辅助加热40MW
  • ⚙️SPARC (CFS) 紧凑型高温超导托卡马克，目标2025年建成，Q>2
来源: ITER.org, 中科院等离子体所, Nature Physics 2024

⚖️ 两大技术路线对比

🧲 磁约束 (MCF)

  • 托卡马克、仿星器、球形环
  • 稳态等离子体，磁场约束
  • ITER、EAST、W7-X
  • 适合连续聚变发电
  • 工程复杂度高，第一壁挑战

🎯 惯性约束 (ICF)

  • 激光驱动、Z箍缩、重离子
  • 脉冲式微爆，极高密度
  • 美国NIF 2022年实现净能量增益 (2.05MJ输入→3.15MJ输出)
  • 高重复频率工程难题
  • 适用于混合堆或未来发电
